### Added

- **Path allowlist for wildcard routes** (#47). A route like `/r/foo/* -> https://svc/test` can now list the sub-paths it exposes, e.g. `/foo1` and `/foo2`. Unlisted paths such as `/r/foo/foo3` get a `404 PATH_NOT_ALLOWED` and never reach the target. A trailing `/*` allows a whole subtree (`/v1/models/*`), and `*` in the middle matches one segment. Traversal tricks (`..`, `%2e%2e`, `%2F`, backslashes) never match. Applies to HTTP and WebSocket. Set it in the route form under **Exposed paths**; an empty list forwards everything as before.
- **Path allowlist templates.** Built-in templates for OpenAI (inference only or full API), OpenAI-compatible servers (vLLM, LiteLLM, LocalAI, LM Studio, llama.cpp), Anthropic, Ollama (inference only, no pull/push/delete), Google Gemini, Mistral, Hugging Face TGI and TEI, n8n webhooks and forms, and health endpoints. Load one with **Replace** or **Add**, or save the current list as your own template with **Save as template**. Custom templates belong to the route's organization, or are global when an admin saves them without one.

### Upgrade notes

- Two database migrations (`20261030100000_route_path_allowlist`, `20261030110000_path_templates`) run automatically on startup. Both only add a column and a table, so existing routes keep forwarding all paths.
- New API endpoints: `GET/POST /api/path-templates`, `PUT/DELETE /api/path-templates/{id}`. Routes accept a new optional `pathAllowlist` field.
