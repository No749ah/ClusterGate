### Security

- **systeminformation 5.33.10 → 5.33.19** (transitive via `@opentelemetry/instrumentation-host-metrics`). Fixes Windows command injection in `services()` through Unicode quotation marks (high), prototype pollution in `networkStats()` via the interface name (moderate) and a symlink-based path traversal in Linux `networkStats()` (moderate).
- **qs 6.16.0 → 6.16.2** (transitive via `express` / `body-parser`). Fixes an uncaught `TypeError` (DoS) in `qs.stringify` with `arrayFormat: 'comma'` (moderate).
- **express 4.22.2 → 4.22.3**, which pulls in `path-to-regexp ~0.1.13` and `qs ~6.16.0`.
- The `qs` override in `backend/package.json` is raised to `>=6.16.2` so a later lockfile refresh cannot fall back to a vulnerable version.
