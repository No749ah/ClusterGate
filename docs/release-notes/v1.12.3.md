### Upgrade notes

- **Database migration:** `20261005090000_request_log_source` adds a `source` column (`TRAFFIC` / `TEST` / `HEALTH_CHECK`) and an index to `request_logs`, and backfills existing rows. The backend applies it automatically on startup (`prisma migrate deploy`). On very large `request_logs` tables the backfill `UPDATE` can take a moment.
- **Request log defaults changed:** route test-panel runs and health-check probes (detected by user agent, e.g. `kube-probe`, Uptime Kuma, UptimeRobot, ELB, GoogleHC) are now hidden from the request log by default. Use the new source filter on the Activity page, the "Show tests & health checks" switch on a route's log tab, or `?source=all` on `/api/logs` to see them.

### New

- **Streamed responses are visible in the request log.** Instead of `[streamed]`, the log keeps the first 5000 characters of the streamed body (marked when truncated), decompressed and with the usual PII redaction. SSE / NDJSON bodies show the assembled text with a Raw toggle. The proxied stream itself is unchanged.
